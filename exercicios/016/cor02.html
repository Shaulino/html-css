Cores gradientes CSS

Para colocar uma cor gradiente em CSS, utilize:

        
            <style>
                body{

                 /* Colocar uma cor gradiente */
                    background-image: linear-gradient(to top, #ffffff, #212121);

                    /* min-height = altura mínima */
                    /* 100vh = 100% da altura da tela do navegador */
                    min-height: 100vh;

                    /* Remove a margem padrão da página */
                    margin: 0;

                    /* Não repete o fundo */
                    background-repeat: no-repeat;
                }
            </style>
