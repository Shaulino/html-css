Trampando com as listas ae

Listas ordenadas

Para fazer uma lista ordenada utilize a tag <ol> para criar a "estrutura" da lista.
E para colocar os itens da lista, utilize a tag <li> DENTRO da tag <ol>
Como vemos no exemplo abaixo

  1. Acordar
  2. Cheirar um pókkkkkkj
  3. bater uma na janela
  4. ir tomar café
  5. trampar

Tem como colocar a lista contando a partir do 4 po exemplo, utlizando o parametro 'Start="4"' DENTRO da tag <ol>
Como vemos no exemplo abaixo

  1. Acordar
  2. Cheirar um pókkkkkkj
  3. bater uma na janela
  4. ir tomar café
  5. trampar

E se quiser contar de tŕas pra frente, a partir do 5 por exemplo
utilize o ATRIBUTO "Reversed" dentro do parametro "start="5""
Exemplo: start="5" reversed

  1. Acordar
  2. Cheirar um pókkkkkkj
  3. bater uma na janela
  4. ir tomar café
  5. trampar

Listas não ordenadas

Pra fazer uma lista sem numeração, apenas com bolinhas marcadoras, utilize a tag <ul>, como vemos no exemplo abaixo

  • Acordar
  • Cheirar um pókkkkkkj
  • bater uma na janela
  • ir tomar café
  • trampar

Se quiser mudar as bolinhas utilize o parametro type DENTRO da tag <ul>

Aninhamento de listas

Colocar um <ol> dentro de um <li> que já esta DENTRO DE UM <ol>, gera um ANINHAMENTO.
Como podemos ver no exeplo abaixo:

FRUTAS

  1. Comprar
    1. Melancia
    2. Graviola
    3. Uva
    4. Manga
    5. Maracujá
  2. Já tenho
    1. Banana
    2. Jabutcaba
    3. Framboesa
    4. Goiaba
    5. Siriguela
