Imagem dinâmica

A tag <picture> é usada para trocar imagens automaticamente dependendo do tamanho da tela ou condições do dispositivo. Ela é muito útil para criar sites responsivos
Dentro dela, você pode usar:
<source> → define regras para quando uma imagem deve aparece
<img> → imagem padrão (fallback), usada caso nenhuma regra seja atendida

Tente abrir esse site em vários dipositivos diferentes ou simplesmente aumente e diminua o tamanho do seu navegador,
