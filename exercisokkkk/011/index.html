Usando links externos

Para utilizar os link externos, use a tag <a> para transformar a frase selecionada em link, só que se usar só a tag <a>
o link ele vai substituir a pagina do seu site, para o do link. Para evitar isso use o parametro 'target="_blank"' e o atributo 'rel=external"'
'target="_blank" (cria a janela) e o 'rel="external"' (leva o usuario pra a guia em branco)
